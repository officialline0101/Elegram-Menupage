# Elegram｜施術メニュー一覧（v3.5）

エステサロン「Elegram」のメニュー表ページ（v3.5）。
v2のエディトリアルな雰囲気（アイボリー × 明朝 × ゴールド × ラベンダー）と、v3のカード型の見やすさを両立したデザイン。

## 構成
```
index.html        メニュー表ページ（単体で動作）
assets/
  icons/          カテゴリアイコン11種（PNG）
  img/            ヒーロー写真・テクスチャ・ロゴ・装飾
```

## 使い方
- `index.html` をブラウザで開くだけで表示できます（外部はGoogle Fontsのみ参照）。
- GitHub Pages で公開する場合は、この一式をリポジトリ直下に置けばそのまま動作します。

## 主な特徴
- レスポンシブ対応（スマホ1列／タブレット2列／PCサイドレール＋3列）
- カテゴリのフィルター（カテゴリ・ナビ）
- カードタップで各カテゴリのコース一覧モーダルを表示
